# 🩺 ตารางเวรพยาบาล/ผู้ช่วยพยาบาล

แอพตารางเวรสไตล์คาวาอิ สำหรับพยาบาลและผู้ช่วยพยาบาล มี 2 เวอร์ชัน

## ฟีเจอร์
- ปฏิทินรายเดือน ลงเวรด้วยสัญลักษณ์: `-` เช้า, `X` บ่าย, `O` ดึก, `Su Sa M T W Th F` หยุดแต่ละวัน, `V` ลาพักร้อน, `LK` ลากิจ, `LS` ลาป่วย
- เวรควบ `-/X`, `-/O`, `X/O` (คิดเงินแค่เวรเดียว ตั้งต้นเป็นเวรแรก)
- OT เช้า/บ่าย/ดึก ต่อวัน
- คำนวณเงินเวรและเงิน OT รายเดือน ตั้งอัตราเองได้
- สติกเกอร์แอนิเมชัน ไฮไลต์ช่อง โน้ตในช่อง
- แจ้งเตือนตามเวรและข้อความที่พิมพ์เอง พร้อมเสียง
- (เฉพาะ Android) เพิ่มไฟล์เสียงและอัดเสียงเองเป็นเสียงแจ้งเตือน

## โครงสร้าง
| โฟลเดอร์ | คืออะไร |
|---|---|
| `docs/` | เว็บแอพ (PWA) ติดตั้งลงหน้าจอโฮมได้ เก็บข้อมูลในเบราว์เซอร์ |
| `android/` | โปรเจกต์ Android Studio (Kotlin + Jetpack Compose) แจ้งเตือนจริงตามเวลา |

## เปิดเว็บแอพด้วย GitHub Pages
1. ไปที่ **Settings > Pages**
2. ที่ Source เลือก **Deploy from a branch** แล้วเลือก Branch `main` โฟลเดอร์ `/docs` กด Save
3. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
4. เปิดใน Chrome บนมือถือ แล้วเลือก **ติดตั้งแอป** จากเมนู ⋮

> การแจ้งเตือนตามเวลาจริงตอนปิดแอพ ทำงานเฉพาะเวอร์ชัน Android

## Build แอพ Android
1. เปิด Android Studio > **File > Open** เลือกโฟลเดอร์ `android`
2. รอ Gradle Sync (ครั้งแรกต้องมีอินเทอร์เน็ต)
3. กด Run ▶ หรือ **Build > Generate App Bundles or APKs > Generate APKs**

ต้องใช้ Android 8.0 (API 26) ขึ้นไป

## หมายเหตุ
- โค้ดชุดนี้สร้างด้วย Claude ยังไม่ได้ทดสอบ build บนเครื่องจริงทุกส่วน หากพบ error แก้ไขตามข้อความที่ขึ้นได้เลย
- ข้อมูลเวรเก็บในเครื่องของแต่ละคน ไม่มีเซิร์ฟเวอร์
